# PBZStats 影之刃零 · 死亡统计 HUD v3.7.1

在游戏画面右侧中部显示 5 行信息（语言自动跟随游戏）：

```
当前周目      第 1 周目
当前难度      逆天者
死亡总数      112
当前 Boss     金面具黑衣人
本 Boss 死亡  24
```

- **传统 mod 形态**：所有文件装在游戏本体目录，游戏启动时由模组自身拉起 HUD，**没有自启项、没有后台监听进程、不需要 Python / .NET 运行时安装**（HUD 使用 Windows 自带的 .NET Framework 4.8）。
- **HUD 随游戏退出**：游戏关闭后 HUD 约 15 秒自动结束。
- **启动有反馈**：托盘区出现「PBZStats HUD」图标 + 气泡提示，右键可退出、打开数据文件夹。
- **语言自动跟随游戏**：支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、意大利语、泰语、越南语（共 13 种，覆盖 Steam 页面列出的全部区域语言）。**在游戏设置里切换语言后几秒内自动跟随，无需重启游戏。**
- **长 Boss 名自动截断**：俄/德/法等语言下 Boss 名过长时按像素宽度裁剪并加“…”（阈值可在 ini 调整），不会顶出屏幕右边缘。
- **数据集中存放**：全部数据与日志在 `PBZStatsHUD.exe` 同目录的 `data\` 文件夹，不玩了直接删这个文件夹即可。

---

## 零、下载哪个包？

本模组有两个版本，版本号相同、游戏内效果相同，唯一区别是**是否附带可选的独立覆盖层 exe**：

| 包 | 内容 | 适合谁 |
| --- | --- | --- |
| **纯 PowerShell 版**（N 网下载的包、GitHub 的 `*_noexe.zip`） | Lua 模组 + UE4SS + `run.ps1` + `PBZStatsHUD.cs`，**磁盘上没有任何 exe** | 默认选这个。杀毒软件没有可隔离的目标。 |
| **完整版**（GitHub release 的 `PBZStatsHUD_v3.7.1.zip`） | 以上全部 **再加** `PBZStatsHUD.exe` + `hudbox.dat` | 需要 `hud_mode=exe` 老式覆盖层、或断网/受限机器想留一个独立 exe 的情况。 |

- 默认模式是 `hud_mode=ps`：模组会启动一个隐藏的 PowerShell 宿主，在内存里编译 `PBZStatsHUD.cs` 并绘制 HUD，**不会写任何 exe 到硬盘**。
- `hud_mode=exe` 只有完整版能用（它需要 `PBZStatsHUD.exe`）。
- 两个包的安装、更新、卸载步骤完全一样。

## 一、安装

1. 关闭游戏。
2. 解压本压缩包，右键 `install.ps1` → **使用 PowerShell 运行**（或命令行 `powershell -ExecutionPolicy Bypass -File install.ps1`）。
3. 脚本会自动寻找游戏目录（Steam 库），找不到时手动指定：
   `powershell -ExecutionPolicy Bypass -File install.ps1 -GameDir "G:\SteamLibrary\steamapps\common\PBZ"`
4. 脚本会安装：
   - `platform\steam\dwmapi.dll`（UE4SS 注入器）
   - `platform\steam\ue4ss\`（UE4SS 与 PBZStats 模组）
   - `platform\steam\ue4ss\Mods\PBZStats\` 内含 `main.lua`、`run.ps1`、`PBZStatsHUD.cs`、`PBZStatsHUD.ini`，数据写入其下的 `data\` 文件夹（完整版另有 `PBZStatsHUD.exe` + `hudbox.dat`；纯 PowerShell 版没有 exe，安装器会打印 `HUD exe (optional): not shipped in this build`）
   - `platform\steam\.pbzstats_version`（本模组自己的安装标记）
5. 从 Steam 正常启动游戏即可：进入游戏后右侧出现 HUD，同时托盘出现图标。

### 安装器行为（重要，避免误会）

- **有状态显示**：每一步打印 `[n/8]`，每个动作打印 `OK` / `WARN` / `FAIL`，最后输出 `RESULT: INSTALL SUCCESSFUL`（安装成功）/ `INSTALLED WITH WARNINGS`（有警告）/ `FAILED`（失败），退出码分别为 0 / 0 / 1。完整记录写入 `%TEMP%\PBZStats_install_<时间戳>.log`；双击运行会保留窗口，方便查看结果。
- **首次安装**：若检测到别人的 `ue4ss\` 或 `dwmapi.dll`（例如另一个 UE4SS mod），会先改名备份再安装，最多保留 2 份备份，不会覆盖丢失你的东西。
- **重复安装/更新**：检测到 `.pbzstats_version` 标记后视为“自己的安装”，**直接就地覆盖、不再产生备份**。
- **-NoBackup**：给高级用户，明确要求不备份、直接替换（仅在确认没有其他 UE4SS mod 时使用）。
- **更新保留数据**：重复安装/升级会自动保留 data\ 里的统计与日志。
- 手动安装（不想用脚本）：把 `files\dwmapi.dll` 与 `files\ue4ss` 复制到 `<游戏>\platform\steam\`，覆盖同名文件前请先备份。

## 二、卸载

运行 `uninstall.ps1`：停止 HUD、删除 `ue4ss\Mods\PBZStats`（含 `data\` 数据）、恢复被改名的 `dwmapi.dll` 备份，并清理 `.pbzstats_version`。
加 `-KeepData` 会先把 `stats.json / stats.txt / 日志` 备份到 `%LOCALAPPDATA%\PBZStats_backup_<时间戳>` 再删除。
卸载同样打印 `[n/8]` / `OK` / `WARN` / `FAIL`，最后输出 `RESULT: UNINSTALL SUCCESSFUL`（卸载成功）/ `UNINSTALLED WITH WARNINGS` / `FAILED`，退出码 0 / 0 / 1，记录写入 `%TEMP%\PBZStats_uninstall_<时间戳>.log`。


## 三、显示内容与数据来源

| 行 | 来源 |
| --- | --- |
| 当前周目 | `PBZGameSystem.CycleCount + 1` |
| 当前难度 | `PBZGameSystem.DifficultModeByte`（0 残障 / 1 入阵者 / 2 破局者 / 3 逆天者 / 4 六十六天） |
| 死亡总数 | `PBZGameSystem.DiedTimes`（与游戏存档累计死亡一致） |
| 当前 Boss | 血条控件的本地化文本（`WB_BossHPBar.BossName`），取不到时回退为类名 |
| 本 Boss 死亡 | 存档 JSON 的 `BossRecord[类名].Records["<周目>_<难度>"].AttemptCount − KillCount` |

- “本 Boss 死亡”与小黑盒同口径：**战斗次数 − 击杀次数**。开打瞬间 `AttemptCount` 已 +1，因此战斗中显示值会 −1；被击杀后恢复为真实次数。
- 首次遇到某个 Boss、或旧存档没有该记录时，回退到本 MOD 自己记录的计数。
- MOD 只读游戏内存数据，**不修改存档、不改游戏文件**。

## 四、启动反馈与关闭方式

- **确认是否在运行**：托盘区出现「PBZStats HUD」图标并弹出气泡；游戏内右侧出现 5 行文字也说明正在运行。
- **关闭显示**：右键托盘图标 → 「退出 HUD」；或直接关闭游戏（约 15 秒后自动退出）；也可命令行 `PBZStatsHUD.exe --quit`。
- **完全卸载**：运行 `uninstall.ps1`（见第二节）。
- 托盘菜单「打开数据文件夹」可一键定位到 `data\`。

### 默认：PowerShell 宿主绘制（不落地 exe）
从 3.7.0 起，HUD 由 mod 启动一个隐藏的 PowerShell 宿主（`run.ps1` + `PBZStatsHUD.cs`）在内存里编译并绘制，**过程中不会生成任何 exe 文件**，因此不会被杀软当作可疑程序隔离；样式、Ctrl+F8 设置页、托盘、跟随游戏语言等全部与旧 exe 版一致。
想用旧的独立 exe（例如离线机器没有 PowerShell 5.1）时，把 ini 里的 `hud_mode` 改成 `exe`；`hud_mode=both` 两个都跑，`hud_mode=none` 关闭 HUD。

需要 Ctrl+F8 设置页面（或喜欢独立置顶覆盖层）时，把 ini 里的 `hud_mode` 改成 `exe`；`hud_mode=off` 关闭 HUD。

## 五、设置页面（Ctrl+F8）

游戏运行时按 **Ctrl+F8**（默认，可改），或在托盘右键 → 「设置」，会在游戏画面上层打开设置面板：

- **快捷键**：点一下输入框，直接按新的组合键（至少含一个 Ctrl/Alt/Shift/Win），立即生效并保存；下面会提示是否注册成功（被其它软件占用会失败）。
- **显示行**：取消勾选某一行，该行就**彻底不渲染**，其余行自动上移，不留空档；立即保存。
- **文字大小**：`−` / `+` 调整（8–72），也可以在下面的自由调整模式里微调。
- **文字对齐**：选「靠右」时五行文字贴右边缘（标签紧贴数值），选「靠左」时标签从左边起排；立即保存并马上应用到 HUD。
- **自由调整 HUD 位置**：点按钮后设置面板会隐藏，HUD 进入拖动模式——五行按真实大小画出，下方有「字体 / Font − N +」和「完成 / Done」。鼠标移到文字上会变成移动光标，按住左键即可把 HUD 拖到任意位置；点「完成」保存（写入 `margin_right` / `offset_y`）并固定，按 Esc 放弃并回到原位。

所有改动**立即写入** `PBZStatsHUD.ini`，重启游戏后保持。

## 六、HUD 配置文件

配置文件：`platform\steam\ue4ss\Mods\PBZStats\PBZStatsHUD.ini`

- `hud_mode=ps`：`ps`（默认）由 PowerShell 宿主在内存里编译绘制，不落地 exe；`exe` 使用随包附带的 `PBZStatsHUD.exe`；`both` 两者都启动；`none` 关闭 HUD。
- `lang=auto`：跟随游戏语言；也可固定为 `zh`/`zht`/`en`/`ja`/`ko`/`fr`/`de`/`es`/`pt`/`ru`/`it`/`th`/`vi`。
- `align=right`：HUD 内文字对齐方式，`right` 贴右边缘（标签紧邻数值左侧）、`left` 标签从左侧起排。难度名称可在 `data\hud_diffnames.txt` 里用四行覆盖。
- `data_dir=` 留空 = 使用 `PBZStatsHUD.exe` 同目录下的 `data\`。
- `max_value_width=620`：数值列（主要影响 Boss 名）最大像素宽度，超出部分以“…”结尾；嫌短可调大。
- `font_size=26`、`line_gap=8`、`gap=14`、`margin_right=40`、`offset_y=0`：字号与位置。`gap` 是标签与数值之间的间距，越小越紧凑。
- `poll_ms=250`、`stale_ms=15000`。

## 七、杀软说明（重要）

3.7.0 起默认由 PowerShell 宿主绘制、不落地 exe，正常情况下不会再触发拦截；只有把 `hud_mode` 设为 `exe` 时才需要把 `PBZStatsHUD.exe`（或整个 `PBZStats` 目录）加入信任区。

HUD 是未签名的独立小程序 `PBZStatsHUD.exe`。部分安全软件（360 安全卫士等）会把“新出现的未签名 exe”直接隔离，表现为**游戏内看不到 HUD，且 mod 目录里的 exe 消失**。

处理方式（任选）：

1. 把 `<游戏>\platform\steam\ue4ss\Mods\PBZStats` 加入安全软件白名单/信任目录，然后重新运行 `install.ps1`。
2. 或临时关闭安全软件的“主动防御/文件保护”，重新运行 `install.ps1`。
3. 模组自带备份文件 `hudbox.dat`：游戏启动时会自动复制回 `PBZStatsHUD.exe` 再运行，因此加入白名单后无需重新安装。

发布包本身不含任何可疑代码；若仍有疑虑可只保留 Lua 数据层（`data\stats.json` 仍会生成，只是不显示 HUD）。

## 八、常见问题

- **双击 exe 没反应**：没有游戏时 HUD 不显示窗口，属正常；看托盘图标是否出现。
- **进游戏没有 HUD**：先看 `data\hud.log` 与 `data\pbzstats.log`。若 exe 被删，见上一节。
- **数字一直是 0**：HUD 只在进入存档后读取真实数据；主菜单显示占位 0 属正常。
- **Boss 名显示为类名**：该 Boss 血条未暴露本地化文本，属回退显示。
- **Boss 名被截断**：正常行为，调大 `max_value_width` 可显示更多字符（屏幕装得下的前提下）。
- **难度对不上**：难度取自存档字节，与读档界面显示一致。
- **想清空数据**：关闭游戏后删除 `data\` 文件夹，下次启动自动重建。
